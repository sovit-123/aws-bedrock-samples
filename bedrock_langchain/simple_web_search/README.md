# Web Search with LangChain

This folder contains two scripts:

* `web_search_langchain.py`: A simple single turn web search agent created with LangChain, Bedrock, and Tavily web search. The user asks a question and the agent answers.
* `web_search_langchain_multi_turn.py`: This is a more complete version with multi-turn chat, memory management, and ability to search web multiple times when prompted.



**Requiremets**: Add the the `TAVILY_API_KEY` API key to your `.env` file.

```
TAVILY_API_KEY=YOUR_API_KEY
```
